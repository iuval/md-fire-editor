Markdown notes

FireMD is a notes app for Markdown, with real-time collaboration.

You write in plain Markdown and FireMD keeps it that way. Notes live in folders, sync between your devices as you type, and can be shared with other people, each with their own permission. The same notes can be read and edited by an AI agent you authorise, through a command line interface or an MCP server.

Open the editor See pricing

You can try it without an account: open the editor and start typing. Signing in with Google keeps the notes on your account and makes them reachable from other devices.

What FireMD is for

It is for people who keep notes in Markdown and want them to behave like files, not like a proprietary document. Four things it does:

Writing that stays Markdown

Headings, lists, tables, code blocks, properties. The note you export is the note you wrote, and the vault can be opened in Obsidian or any other editor.

Real-time collaboration

Two people can type in the same paragraph without overwriting each other. Cursors and selections are visible, and edits merge as soon as the connection allows.

Permissions that hold

Owner, can edit, read only, per note and per folder. Revoking access takes effect immediately, because the rules that decide it run on the server.

Agents, on your terms

A CLI and an MCP server let an AI agent read and edit notes with exactly the permissions you grant, in plain text, with an etag guard against overwriting.

Who it is for

People who already write in Markdown, small teams sharing a notes folder, and anyone who wants an AI agent to work on their notes without handing over an account. It is a web app, installable as an app, and it keeps working offline with the notes you already opened.

What it costs

There is a free daily quota: 100 MB of storage and 700 operations per day, no card required. Beyond that, usage is paid from a prepaid balance bought in packs of 1, 5 or 20 US dollars, charged per unit at published prices. No subscription.
